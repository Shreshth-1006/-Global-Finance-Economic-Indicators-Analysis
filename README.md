# 🌍 Global Finance & Economic Indicators Analysis

> **Understanding Economic Trends, Financial Markets, and Global Stability using Exploratory Data Analysis (EDA)**

## 📖 Overview

This project explores global financial and economic indicators across multiple countries using **Python** and **Exploratory Data Analysis (EDA)**. The analysis focuses on understanding how key macroeconomic indicators influence economic performance, financial markets, and overall stability.

The notebook examines important variables such as GDP growth, inflation, interest rates, unemployment, stock market performance, trade activity, and political stability to uncover trends, correlations, and meaningful insights.

## 📦 Installation

Clone this repository:

```bash
git clone https://github.com/your-username/global-finance-economic-indicators-analysis.git
```

Move into the project directory:

```bash
cd global-finance-economic-indicators-analysis
```

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

Run the notebook:

```bash
jupyter notebook
```

or open it in **Google Colab**.
